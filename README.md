# Habit Tracker

A personal habit, task, and note tracking dashboard built with React, Tailwind CSS, Recharts, and Lucide icons. Data is saved to the browser's `localStorage`, so progress persists across refreshes on the same device/browser.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

This outputs a static site to the `dist/` folder, which can be deployed to any static host (Vercel, Netlify, GitHub Pages, etc).
